# @api-studio-core/core

The shared engine of the API Studio JavaScript SDKs: offline queue, on-device
redaction, batched uploads with the protocol's retry rules, and fetch/XHR
instrumentation. Use [`@api-studio-core/react-native`](../react-native),
[`@api-studio-core/browser`](../browser), or [`@api-studio-core/node`](../node) in apps.
Use this package to build an SDK for another JavaScript runtime.
